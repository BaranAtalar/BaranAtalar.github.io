# Baran Atalar

Personal academic website, prepared for `https://baranatalar.github.io/`.

## Publishing

Use the `BaranAtalar/BaranAtalar.github.io` repository. Publish the `main` branch from `/ (root)` in Settings → Pages → Deploy from a branch. The site is plain HTML, CSS, and JavaScript; no build step is required. The `.nojekyll` file disables Jekyll processing.

## Editing

- `index.html`: biography, news, and publications.
- `miscellaneous.html`: Reviewing and Teaching page.
- `style.css`: shared design and responsive layout.
- `site.js`: publication filters, figures, and citations.
- `assets/Baran-Atalar-CV.pdf`: CV opened in a new tab.

Font licenses are included in `assets/fonts/`.
